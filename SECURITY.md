# Security

There is no supported public release while the fresh package line is under
development. Security reports about the development source are still welcome.

When GitHub's private vulnerability reporting form is available, report
suspected vulnerabilities there:

https://github.com/RocketsAreNostalgic/ran-wp-release-updater/security/advisories/new

If that form is unavailable, open a public issue containing only a request for
confidential contact. Do not include vulnerability details, repository or
WordPress credentials, access tokens, signed URLs, raw HTTP responses, release
assets, temporary paths, site data, or log extracts in a public issue.

Include the package, WordPress, and PHP versions in a private report. State the
provider and affected update operation, but redact repository and site
identities when they are not needed to reproduce the problem.
